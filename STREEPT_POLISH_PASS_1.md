# Streept Polish Pass 1

This pass moves the existing Streept foundation toward a finished product feel without changing navigation logic or adding paid dependencies.

## Focus

- One consistent electric-green action/route language.
- Stronger visual hierarchy for search, trip review, and active navigation.
- More refined glass surfaces, borders, shadows, focus states, and hover states.
- Cleaner mobile sizing for the main trip-planning surfaces.
- Subtle map-edge vignette that does not intercept map interaction.
- Light mode receives the same hierarchy rather than dark-only styling.
- Route-preview loading state gets a restrained progress sheen.

## Intentionally unchanged

- Routing logic
- Navigation intelligence
- Backend/API contracts
- Database behavior
- Billboard functionality
- Parking functionality
- Unit-test suite
- GitHub CI unit/build coverage
- E2E removal decision from the previous release
