# Streept Alpha 8 — Guidance Layer

- Added native browser voice guidance for approaching complex maneuvers.
- Added 400m / 150m / 50m announcement thresholds with per-maneuver de-duplication.
- Cancels active speech when navigation stops or a new maneuver replaces the previous one.
- Added spoken arrival confirmation.
- Keeps the feature keyless and works with the platform speech engine.

This is a web prototype capability; native mobile builds should later use platform TTS for background/reliable audio sessions.
